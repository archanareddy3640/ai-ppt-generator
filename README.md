# 🚀 AI PowerPoint Generator

An AI-powered web application that generates professional PowerPoint presentations instantly based on a topic, number of slides, and tone.

---

## 🌐 Live Demo

👉 https://ai-ppt-generator-orcin.vercel.app

---

## ✨ Features

* 🧠 AI-generated slide content (OpenRouter - Llama 3)
* 🎯 Dynamic slide count selection
* 🎨 Clean and professional slide layout
* 📝 Tone customization (Formal, Creative, Professional)
* 📥 Instant PPT download
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

* Frontend: Next.js (App Router), TypeScript, Tailwind CSS
* Backend: Next.js API Routes
* AI: OpenRouter API (Llama 3)
* PPT Generation: PptxGenJS
* Deployment: Vercel

---

## ⚙️ How It Works

1. Enter a topic
2. Select number of slides
3. Choose tone
4. AI generates structured slide content
5. PPT is created and downloaded instantly

## 🔑 Environment Variables

Create a `.env.local` file in the root and add:

OPENROUTER_API_KEY=your_api_key_here

⚠️ Do not push this file to GitHub.

---

## ▶️ Run Locally

npm install
npm run dev

Open http://localhost:3000

---

## 🚀 Deployment

Deployed using Vercel:

1. Connect GitHub repository
2. Import project
3. Add environment variables
4. Deploy
